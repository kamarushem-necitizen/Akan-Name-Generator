# Akan-Name-Generator
## Project name
Akan-Name-Generator

## Project Description
I built an Akan Name Generator web application inspired by the Akan naming tradition in Ghana. The application allows users to enter their date of birth and select their gender. It then calculates the day of the week they were born and displays their corresponding Akan name.

2. Open the project folder.
3. Open index.html in a web browser.

## BBD (Behavior-Driven Development)
- User enters a valid birth date and gender - The application displays the correct Akan name.

- User leaves the birth date empty - User leaves the birth date empty

- User does not select a gender - The application displays an error message

- User enters invalid information - The application asks the user to provide valid details.

- User clicks the Generate Name button - The application calculates the birth day and returns an Akan name.
